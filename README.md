# 💇‍♀️ Салон красоты «Гармония» — мини-CRM с онлайн-записью

Учебный fullstack-проект: сайт салона красоты с онлайн-записью клиентов и защищённой админ-панелью для персонала. Демонстрирует полный цикл работы веб-сервиса: от выбора услуги клиентом до управления записями администратором.

> Все данные, адреса, телефоны и отзывы выдуманы — проект создан в учебных целях.

## Возможности

**Для клиентов**
- запись онлайн за 4 шага: услуга → мастер → дата и время → контакты
- автоматический расчёт свободных слотов с учётом длительности услуги и занятости мастера
- карточки мастеров с фото, рейтингом, стажем и списком услуг
- маска ввода телефона `+7 (999) 123-45-67`
- скачивание напоминания в календарь (`.ics`) после записи
- блок «О салоне» с контактами, отзывами и кнопками связи

**Для персонала** (`/admin.html`)
- вход по JWT-токену (bcrypt-хеши паролей)
- статистика: выручка по завершённым записям, записи за месяц, предстоящие визиты
- таблица записей с фильтром по дате
- смена статуса, редактирование и удаление записей с проверкой пересечений по времени
- добавление мастеров (с привязкой услуг) и услуг

**Безопасность**
- JWT (HS256) с проверкой срока действия
- bcrypt-хеширование паролей
- защита публичного API и логина от перебора: rate limit 5 запросов/мин с IP
- валидация имени и телефона на сервере (Pydantic) и клиенте
- защита от XSS при рендеринге данных в админке (`textContent`)
- CORS только для локальных источников

## Стек

| Слой | Технологии |
|---|---|
| Backend | Python, FastAPI, SQLAlchemy 2.0, Pydantic v2, PostgreSQL |
| Авторизация | PyJWT, bcrypt |
| Frontend | HTML, Tailwind CSS (CDN), чистый JavaScript |
| Инфраструктура | uvicorn, python-dotenv |

## Структура проекта

```
app/
  main.py          # FastAPI-приложение, CORS, миграции, статика
  database.py      # подключение к БД
  models.py        # User, Master, Service, Appointment
  schemas.py       # Pydantic-схемы и валидация
  security.py      # bcrypt, JWT, get_current_admin
  rate_limit.py    # in-memory rate limiter
  routers/
    public.py      # публичный API: услуги, мастера, слоты, запись
    admin.py       # админский API: логин, статистика, CRUD
frontend/
  index.html       # сайт салона с онлайн-записью
  app.js           # логика визарда, маска телефона, .ics
  admin.html       # админ-панель
  admin.js         # логика админки
seed.py            # создание администратора и демо-данных
```

## Запуск

```bash
# 1. виртуальное окружение
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/macOS

# 2. зависимости
pip install -r requirements.txt

# 3. конфигурация
copy .env.example .env        # Windows
# cp .env.example .env        # Linux/macOS
# укажите DATABASE_URL и сгенерируйте SECRET_KEY:
# python -c "import secrets; print(secrets.token_hex(32))"

# 4. база данных и демо-данные
python seed.py

# 5. запуск
uvicorn app.main:app --reload
```

- Сайт: http://127.0.0.1:8000/
- Админ-панель: http://127.0.0.1:8000/admin.html
- Документация API: http://127.0.0.1:8000/docs
- Доступ администратора по умолчанию: `admin` / `admin123` (**смените пароль в реальном проекте**)

## Переменные окружения

| Переменная | Описание |
|---|---|
| `DATABASE_URL` | строка подключения к PostgreSQL |
| `SECRET_KEY` | секрет для подписи JWT |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | время жизни токена (по умолчанию 480 — рабочая смена) |

## API

**Публичные**

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/services` | список услуг |
| GET | `/api/masters?service_id=` | мастера (опционально по услуге) |
| GET | `/api/slots?master_id=&service_id=&date=` | свободные слоты на дату |
| POST | `/api/appointments` | создание записи (rate limit 5/мин) |

**Админские** (заголовок `Authorization: Bearer <token>`)

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/admin/login` | вход, выдача JWT (rate limit 5/мин) |
| GET | `/api/admin/stats` | выручка, записи за месяц, предстоящие |
| GET | `/api/admin/appointments?date=` | список записей с фильтром |
| PATCH | `/api/admin/appointments/{id}` | редактирование / смена статуса |
| DELETE | `/api/admin/appointments/{id}` | удаление записи |
| POST | `/api/admin/services` | создание услуги |
| POST | `/api/admin/masters` | создание мастера с привязкой услуг |

## Бизнес-правила

- рабочие часы: ежедневно 10:00–20:00, шаг слотов 30 минут
- запись не может пересекаться с другой записью того же мастера (с учётом длительности услуги)
- отменённые записи освобождают слот
- мастер выполняет только привязанные к нему услуги
